# mac-tg-bot — обновление с inline-кнопками

## Что изменено
- `server/main.py` — inline-клавиатура Telegram, кнопки открытия страниц unu.im, статуса, скриншота, назад и закрытия.
- `agent/agent.py` — открытие ссылок в Google Chrome на Mac, «Назад» и сочетание Shift+` (на русской раскладке обычно Shift+Ё).
- Остальные команды и файлы проекта сохранены.

## Какие файлы заменить
В репозитории GitHub замени содержимое только этих двух файлов:
1. `server/main.py`
2. `agent/agent.py`

Затем отправь изменения в GitHub. Render автоматически пересоберёт сервер (если включён Auto-Deploy). На Mac обнови `agent/agent.py` и перезапусти агент.

## Важно для macOS
Приложению Terminal/Python может потребоваться разрешение **System Settings → Privacy & Security → Accessibility** для управления клавиатурой через System Events. Если Chrome не реагирует на «Назад» или «Закрытие», проверь это разрешение. Клавиша key code 50 — физическая клавиша grave/tilde; её символ зависит от раскладки.

## Переменные Render
Существующие `BOT_TOKEN`, `OWNER_ID`, `AGENT_KEY`, `WEBHOOK_SECRET` не меняй при обычном обновлении кода. Но если значения с секретами на приложенном скриншоте настоящие, немедленно перевыпусти/замени их: токен бота — через BotFather, а `AGENT_KEY` и `WEBHOOK_SECRET` — на случайные новые значения и синхронно обнови их в Render и `.env` агента на Mac.

## Проверка
1. Открой бота и отправь `/start`.
2. Проверь кнопки «Открыть общую», «odicom», «smm», «jr».
3. Убедись, что Chrome открыт на Mac и агент запущен.
4. Проверь «Скрин», «Назад» и «Закрытие».
